AGENTS.md

OpenAI 的命令列寫程式工具，AGENTS.md 格式的原始推動者。

怎麼載入

  • 每次工作前都會先讀 AGENTS.md
  • 先找全域（~/.codex），再從專案根目錄往下一層一層找
  • 每一層會先看 AGENTS.override.md，沒有才看 AGENTS.md

用在這個專案

  • 直接把 AGENTS.md 放在專案根目錄，不用額外設定
  • 某個子資料夾需要不同規則時，在那裡另放 AGENTS.override.md

注意事項

空檔案會被忽略；沒讀到時，先確認是不是在正確的專案資料夾啟動。
