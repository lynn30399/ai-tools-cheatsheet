Claude Code

CLAUDE.md

Anthropic 的命令列寫程式工具，慣用的設定檔是 CLAUDE.md。

怎麼載入

  • 會讀目前資料夾和往上各層資料夾的 CLAUDE.md
  • CLAUDE.md 裡可以用 @路徑 匯入其他檔案

用在這個專案

  • 專案已經有 AGENTS.md 時，另外建一個 CLAUDE.md，內容只寫一行 @AGENTS.md
  • 想補 Claude 專用的規則，寫在那一行下面

注意事項

Windows 建 symlink 需要管理員權限或開發人員模式，建議用匯入，不要用 symlink。

資料有出入：一份官方文件說 Claude Code 只讀 CLAUDE.md，另一份和第三方整理提到沒有 CLAUDE.md 時會改讀 AGENTS.md，兩者並存以 CLAUDE.md 為準。需再確認最新版行為。

官方文件：https://code.claude.com/docs/en/memory
